# LMS System - Django REST Framework

Система управления курсами и уроками с расширенным функционалом платежей.

## 📋 Описание проекта

Проект представляет собой REST API для образовательной платформы (LMS). Реализована полная CRUD функциональность для курсов, уроков и платежей. 

### Основные возможности:
- 🔐 Кастомная модель пользователя с авторизацией по email
- 📚 Управление курсами и уроками
- 💳 Система платежей с фильтрацией и сортировкой
- 📊 Автоматический подсчет количества уроков в курсе
- 👤 Профиль пользователя с историей платежей

## 🛠 Технологии

- Python 3.10+
- Django 4.2.7
- Django REST Framework 3.14.0
- Django Filter 23.5
- Pillow 10.1.0 (для работы с изображениями)
- SQLite3 (по умолчанию)
