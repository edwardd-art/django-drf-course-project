# Django DRF Course Project

Проект для управления курсами и уроками с использованием Django REST Framework.

## Описание проекта

Проект представляет собой REST API для системы управления образовательными курсами. Включает:
- Кастомную модель пользователя с авторизацией по email
- CRUD операции для курсов и уроков
- Документированное API

## Технологии

- Python 3.10+
- Django 4.2.7
- Django REST Framework 3.14.0
- Pillow для работы с изображениями
